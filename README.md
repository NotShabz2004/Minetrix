# Minetrix
<p>
    To test the project, run the AES.py file and input appropriate values for the folder names to be encrypted. 
</p>

<h2>How it works ?</h2>
<p> The folder's path is given as the input with name of the key file where our randomly generated key is stored. Then the algorithm performs 256-bit AES encryption that can leveled up and generates a new .qvault folder where all the data in it is encrypted. Then, the decryption algorithm works by using the same key saved to encrypt the files</p>
